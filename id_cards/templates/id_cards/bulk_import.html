Bulk Import Staff

Upload a CSV file to create multiple staff records at once. Employee IDs are generated automatically. Each row must have at least a full name.

{# ============================================================ SCHEMA INFO — matches the fields read by bulk_import() in views.py ============================================================ #}
CSV Format
Required
full_name Required Staff member's full name
Identity
designation Optional Job title, e.g. Senior Mathematics Teacher
role Optional Role key: TEACHER, SECRETARY, ACCOUNTANT, PRINCIPAL, etc.
department Optional Department name (must already exist)
levels Optional Semicolon-separated level names, e.g. JSS1;JSS2
Contact
email Optional Contact email address
phone Optional Contact phone number
emergency_contact_phone Optional Emergency contact number (shown on the back of the ID card)
Card validity
valid_thru Optional Expiry date — YYYY-MM-DD or MM/YYYY
issue_date Optional Issue date — YYYY-MM-DD or MM/YYYY
expiry_date Optional Explicit expiry date — YYYY-MM-DD or MM/YYYY
Back-of-card text
id_card_terms Optional Custom terms of use (overrides template default)
authorized_use Optional Custom authorization statement
security Optional Custom security / lost-card notice
The first row of the CSV must be the header row. Unknown columns are ignored. Department and level names are matched case-insensitively.
