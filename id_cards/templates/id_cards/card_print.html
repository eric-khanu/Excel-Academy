Printing tips
Each pair shows the front (left) and back (right) of one card. Cut each pair separately, or print double-sided for a single physical card.
Set Scale = 100% and Margins = None in the print dialog. Turn on Background graphics.
Recommended: 300gsm cardstock, or print on plain paper and laminate for durability.
Each card is CR80 sized (2.125" × 3.375") — standard ID card. Cut along the outer edge with a guillotine.
